# Swiss TIP - knowledge bases

The curated knowledge bases served by the Swiss TIP MCP server. Each pack is
a set of facts about Swiss public information, every one of them tied to an
exact excerpt of an official page, with its URL, access date and hashes, and
reviewed by a person before release.

This repository holds the **data**. The server and the pipeline that builds
these packs are in [swiss-tip](https://github.com/swisstip/swiss-tip).

## The hackathon

Built for the **Swiss {ai} Weeks** hackathon in Zurich, 24 and 25 September
2026, for the challenge **Swiss Grounding MCP**, set by Swisscom's myAI team:

<https://zh.ai-weeks.ch/challenges/swiss-grounding-mcp>
